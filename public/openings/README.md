# Lichess opening definitions

`lichess.json` is derived from the a–e TSV files in https://github.com/lichess-org/chess-openings (retrieved 2026-10-24). The original ECO code, name and PGN are retained, with a normalized position and ply count added using chess.js. Data is licensed CC0; see COPYING.txt.

These definitions identify the starting position of an opening, including transpositions. Continuation frequencies come from the authenticated Lichess Opening Explorer, not this catalog.
